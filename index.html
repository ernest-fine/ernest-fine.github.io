How to use & keyboard shortcuts

Dot / Text: tap the map to place. Arrow / Pen: drag to draw. Select: tap or drag an annotation to edit or move it. On touchscreens, use Select to scroll the map from an empty area; drawing tools capture touch. Pinch zoom is available in Select. Use + / − to zoom for fine placement.

V Select · D Dot · T Text · A Arrow · P Pen · Delete remove selected · Ctrl/⌘ Z undo · Ctrl/⌘ Shift Z redo. Use Tab to focus an annotation, Enter to select it, and arrow keys to move it.
